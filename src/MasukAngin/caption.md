# Caption / deskripsi upload — "kenapa masuk angin?"

## TikTok / Reels (tautan tidak bisa diklik → cukup sumber utama)

```
kenapa masuk angin? padahal jendela udah ditutup 🌬️❌

ternyata bukan angin pelakunya. 5 tersangka aslinya:
1. flu / infeksi saluran napas
2. perut bermasalah (maag, kembung)
3. daya tahan tubuh turun
4. merah kerokan = pembuluh darah kecil pecah, bukan angin keluar
5. "angin duduk" (nyeri dada) bisa tanda masalah jantung — serius!

ke dokter kalau demam > 3 hari, muntah/diare terus, atau nyeri dada.

kamu tim kerokan atau tim minyak angin? tulis di komen 👇
```
