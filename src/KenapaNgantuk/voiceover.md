# Transkrip voiceover — "kenapa habis makan ngantuk?"

> **Penting:** yang ditempel ke tool TTS **hanya teks narasinya** (tabel kolom "Teks" atau blok "Teks polos" di bawah) — jangan seluruh file ini, supaya panduan & tabel tidak ikut terbaca.

Generate **satu file suara per scene** di tool TTS pilihanmu, pakai voice yang sama untuk semuanya.
Simpan dengan nama persis seperti di kolom **File**, lalu taruh di:

```
public/vo/kenapa-ngantuk/
```

Format bebas: `.mp3`, `.wav`, atau `.m4a`. Setelah semua file ada, kabari — durasi tiap scene, munculnya teks, dan ketukan animasi akan dicocokkan ke suaranya.

## Pengaturan yang disarankan

- Bahasa: Indonesia. Gaya: santai, ramah, seperti ngobrol (bukan membaca berita).
- Tempo: normal sampai sedikit cepat. Total semua klip idealnya **35–45 detik**.
- Jangan tambahkan musik atau efek. Jeda hening di awal/akhir tiap file maksimal ±0,3 detik.
- Ucapkan "day one eight" dalam bahasa Inggris (dei wan eit).

## Kalau tool-mu hanya bisa satu file panjang

Tidak apa-apa: generate semua teks di atas berurutan dalam satu file (beri jeda ±1 detik antar nomor), simpan sebagai `full.mp3` di folder yang sama. File itu akan dipotong per scene di sisi proyek.

## Teks polos (untuk disalin sekaligus)

```
Habis makan, langsung ngantuk? Tenang, ini bukan karena kamu malas.

Ada lima alasan kenapa ini terjadi.

Pertama, hormon. Saat mencerna makanan, tubuh melepas serotonin dan melatonin, dua hormon yang bikin ngantuk.

Kedua, aliran darah lebih banyak ke saluran cerna, jadi suplai ke otak sedikit berkurang. Tapi teori ini masih diteliti, ya.

Ketiga, kurang tidur. Badan capek dan gampang lapar, akhirnya makan lebih banyak. Usahakan tidur tujuh sampai sembilan jam.

Keempat, jarang bergerak. Tubuh jadi gampang lelah. Coba jalan kaki lima belas menit setiap hari.

Kelima, gangguan kesehatan, misalnya diabetes, anemia, hipotiroid, atau sleep apnea.

Makanan seperti telur, tahu, ikan, pisang, ceri, teh chamomile, sampai minuman berenergi juga bisa bikin makin ngantuk.

Jadi, ngantuk habis makan itu normal. Tapi kalau sering dan berat, cek ke dokter, ya.

Follow day one eight untuk info lainnya.
```
